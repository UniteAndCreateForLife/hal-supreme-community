# Security Policy

## Reporting a vulnerability

If you discover a security issue in HAL SUPREME (product, gateway, or this community repo):

1. **Do not** open a public GitHub Issue or Discussion with exploit details, tokens, or private data.
2. Report privately via **[GitHub Security Advisories](https://github.com/UniteAndCreateForLife/hal-supreme-community/security/advisories/new)** for this repository.
3. Include a clear description, impact, and steps to reproduce when possible — **without** pasting real credentials.

We will acknowledge reports and work on a fix as capacity allows.

## Never post tokens

- Do not commit gateway Bearer tokens, API keys, Discord bot tokens, or Cloudflare credentials.
- Do not paste secrets into Issues, PRs, Discussions, Discord, or chat.
- Use placeholders such as `<HAL_GATEWAY_TOKEN>` in examples.

## Scope notes

This community repo hosts documentation and examples only. Product/gateway issues should still be reported privately as above when they involve security.
